The smooth muscle in various organs behaves differently, and has specialised contraction/relaxation dynamics.

![Smooth muscle contraction dynamics showing four curves (A-D). C (y-axis) = Contraction/Force, R = Relaxation, t = Time. Curve A (I, green) is sustained high contraction with a brief relaxation dip. Curve B (II, blue) shows sustained partial contraction (tone) with moderate fluctuations. Curve C (III, purple) shows rhythmic phasic oscillations. Curve D (IV, red) shows baseline relaxation with a sharp contraction spike.](/papers/ibo/2023/q2-figure-1.png)
*C = Contraction/Force, R = Relaxation, t = Time. I = Normally contracted, II = Normally partially contracted (tone), III = Phasically active, IV = Normally relaxed.*

Match the four curves (A-D) with the four corresponding organs (1-4):

1. Sphincters
2. Oesophagus, urinary bladder
3. Blood vessels, airways
4. Stomach, intestines
