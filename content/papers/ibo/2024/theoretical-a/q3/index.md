Yerzhan studies the evolution of four closely related bacterial strains (A, B, C, D), focusing on RNA polymerase subunit β and transposase. He reconstructed phylogenetic trees for the two corresponding genes that code for these proteins (Figure 1X, Y) using the alignment of four sequences (representative snapshot is shown on Figure 2) and the most parsimonious solution. He rooted both phylogenies using the D strain as an outgroup. Unfortunately, he realized that he forgot to properly label the datasets. Consequently, he began comparing these phylogenetic trees to the reference phylogenetic tree reconstructed from genes of ribosomal proteins (Figure 1Z).

```
    X          Y          Z
   ┌─ C       ┌─ A       ┌─ A
 ┌─┤         ┌─┤         ┌─┤
 │ └─ B      │ └─ B      │ └─ B
 │           │           │
 ├──── A     ├──── C     ├──── C
 │           │           │
 └────── D   └────── D   └────── D
```
*Figure 1. Phylogenetic trees reconstructed from RNA polymerase subunit β (X or Y), transposase (X or Y) and reference genes of ribosomal proteins (Z).*
