<section class="biolab-section">
  <h2>Mandatory baseline, optional everything else</h2>
  <div class="biolab-decision-grid">
    <div class="biolab-decision-card biolab-decision-locked">
      <h3><span class="biolab-decision-icon">&#10003;</span>Mandatory baseline</h3>
      <ul>
        <li><strong>BiOGuide's own verified, correctly-attributed protocols</strong> form the baseline, not the last.</li>
        <li><strong>No hazardous methods</strong> - never real blood self-sampling, never dangerous material use without proper guidance. Period.</li>
        <li>Submitted results stay <strong>private by default</strong>; publishing them is always the submitter's choice.</li>
        <li>Any photo you upload will have its <strong>EXIF metadata stripped</strong> before it's stored.</li>
      </ul>
    </div>
    <div class="biolab-decision-card biolab-decision-open">
      <h3><span class="biolab-decision-icon">&#9675;</span>Always optional</h3>
      <ul>
        <li>Leaving <strong>feedback or comments</strong> on any protocol, BiOGuide's or a peer's.</li>
        <li>Submitting <strong>your own results</strong> - the phone-camera capture-and-compare tool is one option, for protocols with a colorimetric readout.</li>
        <li>Submitting a <strong>brand-new protocol</strong> of your own, on any lab topic - credited to you, published immediately.</li>
        <li>A BiOGuide-verified <strong>reference result</strong> for a given protocol - occasional bonus content, not something every protocol needs.</li>
      </ul>
    </div>
  </div>
  <div class="biolab-caution-box">
    <span class="biolab-caution-label">⚠️ Read before you trust a protocol</span>
    <p>A protocol without a &ldquo;BiOGuide-verified&rdquo; badge <strong>hasn't been checked by our staff</strong>. Anyone will be able to publish a protocol the moment they submit it - there's no review queue before it goes live. Moderation is <strong>report-and-remove only</strong>: use your own judgment, follow your own institution's safety rules, and report anything that looks wrong or unsafe so we can take it down.</p>
  </div>
</section>

<script>
(function () {
  'use strict';
  var groups = document.querySelectorAll('.biolab-reactions');
  if (!groups.length) return;

  var STORAGE_KEY = 'biolab-feedback-v2';
  var state = {};
  try {
    var raw = window.localStorage.getItem(STORAGE_KEY);
    if (raw) state = JSON.parse(raw) || {};
  } catch (e) {}

  function save() {
    try { window.localStorage.setItem(STORAGE_KEY, JSON.stringify(state)); } catch (e) {}
  }

  groups.forEach(function (group) {
    var key = group.getAttribute('data-key');
    var multi = group.getAttribute('data-multi') === 'true';
    var buttons = group.querySelectorAll('.biolab-reaction');

    function applyFromState() {
      var saved = state[key];
      buttons.forEach(function (btn) {
        var value = btn.getAttribute('data-reaction');
        var active = multi ? (Array.isArray(saved) && saved.indexOf(value) !== -1) : (saved === value);
        btn.classList.toggle('is-active', active);
      });
    }
    applyFromState();

    buttons.forEach(function (btn) {
      btn.addEventListener('click', function () {
        var value = btn.getAttribute('data-reaction');
        if (multi) {
          var list = Array.isArray(state[key]) ? state[key].slice() : [];
          var idx = list.indexOf(value);
          if (idx === -1) { list.push(value); } else { list.splice(idx, 1); }
          state[key] = list;
        } else {
          state[key] = value;
        }
        save();
        applyFromState();
        var note = document.getElementById('biolab-reaction-note');
        if (note) note.textContent = "Thanks - saved on this device only. It's not sent anywhere.";
      });
    });
  });
})();
</script>
